# Что изменено относительно chiaki-ng

## v0.1.4 - обновляемая библиотека NR

- Сняты ограничения по SHA256 и подписи nvngx_dlssnr.dll. Можно заменить библиотеку рядом с программой и перезапустить клиент.
- Проверка совместимости при загрузке и инициализации сохранена; имя файла не гарантирует поддержку GPU или интерфейса.
- Общие настройки и регистрации обычного Chiaki сохранены.

## v0.1.3 - сохранённые подключения Chiaki

- Portable снова использует общее хранилище оригинального Chiaki в Windows: регистрации, профили и остальные настройки. Повторная регистрация консоли не нужна.
- Отдельные INI v0.1.2 не удаляются и не перезаписывают существующие данные Chiaki.
- Изменения настроек теперь общие для обоих клиентов; portable не означает отдельную базу подключений.

## v0.1.2 - чистая зависимость NR

- Убраны заголовки NVIDIA SDK из актуального дерева и сборки. Динамический интерфейс NGX описан минимальными объявлениями ABI; чужая реализация SDK не включается в AGPL-форк.
- Повторно проверены сборка и GPU-вызовы с этим интерфейсом.

## v0.1.1 - упаковка и проверка библиотек

- Исправлен поиск Git при сборке архива исходников в Windows.
- Для NR разрешён проверенный локальный runtime или библиотека с действительной подписью NVIDIA Corporation. Совместимость всё равно проверяется драйвером.
- CI дополнительно проверяет, что NR недоступен без runtime.

## v0.1.0 - первый portable Chiaki NR

Основа - chiaki-ng 1.10.0. Подключение к PS4/PS5, управление, звук и привычные настройки Remote Play остаются из исходного проекта.

- Добавлен отдельный экспериментальный DLSS 5 Neural Rendering через Vulkan feature 18. Runtime предоставляется пользователем, в релиз не входит.
- Пространственные скейлеры исходного клиента отделены от Render Preset. Полный исходный кадр масштабируется до области вывода.
- Добавлен управляемый RCAS после масштабирования, перед поправкой NR.
- Добавлена экспериментальная интерполяция видео Optical Flow 2×. Она не использует NVIDIA MFG или FSR FG.
- Добавлена панель Insert с курсором, прокруткой, настройками на лету и схемой обработки.
- Добавлены рабочий масштаб/проходы/стиль/смешивание NR и усиление поправки без замены полноразмерного кадра.
- Добавлен portable-режим с отдельными настройками. Приватные подключения не входят в сборку.
- Переключатель NR ограничен NVIDIA RTX с библиотекой; AMD, Intel и GTX продолжают обычный стриминг без NR.
- Добавлены упаковка, контрольные суммы и выпуск через GitHub Actions.

Это экспериментальная доработка клиента, а не гарантия качества HDMI или 120 FPS. Проверено локально на RTX 3080; остальные конфигурации требуют проверки.
