# Задачи

## NR-007 - публичный форк и portable
- Статус: BLOCKED (удалённый выпуск). Владелец: основной агент.
- Цель: Chiaki NR portable, README/changelog относительно upstream, AGPL/атрибуция, проверка доступности NR, сборка и выпуск через Actions в goshkow/chiaki-nr.
- Область: main.cpp, nvidiavideo.*, QML панели/название, scripts, .github, README, лицензии и эти документы.
- План: проверить упаковку/лицензии; изолировать portable-настройки и проверять GPU/runtime; собрать и протестировать; подготовить очищенный пакет; отправить исходники и tag по SSH; проверить Actions/релиз.
- Готовность: нет личных данных в пакете; portable хранит настройки рядом; NR недоступен на неподдерживаемом GPU; воспроизводимые инструкции/CI; фактические тесты и честные ограничения.
- Риски: закрытая ShortFuse DLL не имеет подтверждённого права распространения; NR проверен только на RTX 3080. Не обещать 120 FPS или паритет с HDMI. Сторонние лицензии/историю не стирать.
- Сделано: portable-настройки изолированы; добавлены проверки RTX/runtime; RCAS и FG больше не требуют NGX на AMD/Intel; README/changelog/лицензии и workflow готовы. Закрытые DLL и личные данные исключены. Старые workflows сохранены отключёнными.
- Проверки: локальная сборка, GPU-тест, панель Insert (24 сочетания/колесо/границы), portable-check, отсутствие runtime и недоступность NR - код 0. Проверен полный исходный INI на тестовой копии. Ошибка тестового Qt offscreen исправлена использованием Windows-плагина в portable/CI.
- Удалённо: исходники отправлены по SSH в goshkow/chiaki-nr, main и v0.1.0 присутствуют. История upstream сохранена. Добавлена совместимость с подписанными NVIDIA runtime без разрешения неизвестных патчей. Повторные сборка/GPU/QML/portable-проверки прошли с кодом 0.
- Блокер: публичная страница Actions после push показывает 0 запусков; релиз ещё не опубликован. Пользователю отправлен вопрос о включении Actions. По его правилам настройки GitHub не меняются через API или браузер.
- Дополнительно: в v0.1.2 удалены заголовки NVIDIA SDK из актуального дерева. Их заменяет минимальное описание ABI; GPU-тест feature 18/RCAS/FG повторён. Неподписанный случайный runtime проверен отрицательным тестом и не активирует NR. Локальный portable без личных данных и закрытых DLL собран, оригинальная установка не менялась. Description/Topics подготовлены в docs/REPOSITORY.md.
- Следующий шаг: после включения Actions запустить workflow на теге v0.1.2 через интерфейс пользователя либо отправить следующий patch-tag по SSH без перезаписи старого; проверить удалённую сборку и релиз. У workflow dispatch на теге release-шаг выполняется. На main выпускается только artifact. Нельзя утверждать, что Actions или релиз уже прошли.
